# Список без лишнего состояния

## Задача

Доведите `FilterableList` до рабочего состояния: фильтрованный список должен вычисляться во время render, selection — храниться как стабильный `id`, а асинхронный refresh — корректно отменяться при смене loader или unmount.

## Ограничения

- Не храните `filteredItems` в state и не синхронизируйте его effect-ом.
- Не используйте индекс массива как React key.
- Не подавляйте правило `exhaustive-deps`.
- Effect допустим только для синхронизации с loader; добавьте cleanup через `AbortController` или эквивалентный механизм.
- Не мутируйте `initialItems` и результат loader.

## Работа

Заготовка находится в `src/filterable-list.tsx`. Сначала реализуйте чистую `filterItems`, затем поведение компонента. Контрактные тесты намеренно красные; добавьте собственные проверки race/unmount до завершения решения.

Из каталога упражнения:

```text
npm install
npm run typecheck
npm test
```

При запуске через корневой harness зависимости уже доступны после корневого `npm install`.
