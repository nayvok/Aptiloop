# Ограниченный пул запросов

## Задача

Реализуйте `runRequestPool`: функция получает набор ленивых async jobs, запускает не больше `limit` одновременно и возвращает результаты в порядке входного массива, а не в порядке завершения.

Каждый job принимает тот же `AbortSignal`, который передал вызывающий код. При отмене нельзя запускать новые jobs; итоговый promise должен отклониться с причиной из `signal.reason` (или `AbortError`, если причины нет). Уже запущенную работу отменяет сам job через полученный signal.

## Ограничения

- Ограничивайте момент вызова job: нельзя заранее вызвать все функции и затем ограничить только `await`.
- Не меняйте порядок результатов.
- Не проглатывайте первую ошибку job и не запускайте новые jobs после обнаруженной ошибки.
- `limit` должен быть положительным целым числом; иначе бросьте `RangeError` до запуска.
- Не мутируйте массив jobs.
