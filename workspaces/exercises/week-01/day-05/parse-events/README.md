# Парсер доменных событий

## Задача

Преобразуйте недоверенное значение `unknown` в типизированное доменное событие. Успешный результат должен содержать discriminated union, а ошибка — понятный список проблем. После этого реализуйте обработчик всех вариантов события с compile-time проверкой исчерпывающего `switch`.

## Ограничения

- Не используйте `any` и внешние schema-библиотеки.
- Проверяйте во время выполнения каждое поле, которое попадёт в доменную модель.
- Не ставьте `as DomainEvent` сразу после `JSON.parse`.
- Assertion допустим только после доказанной проверки формы значения.
- Не выбрасывайте исключение для обычной ошибки валидации: верните ветку `{ ok: false }`.

## Работа

Начните с `src/parse-events.ts`. Тесты задают наблюдаемый контракт, но не раскрывают реализацию. Добавьте собственные пограничные случаи до написания основной логики.

Из каталога упражнения:

```text
npm install
npm run typecheck
npm test
```

При запуске через корневой harness зависимости уже доступны после корневого `npm install`.
