# Нормализация профиля

## Задача

Реализуйте чистую функцию `normalizeProfile`, которая принимает `unknown`, проверяет данные во время выполнения и возвращает новый нормализованный профиль либо список ошибок.

Контракт результата уже задан в `src/normalize-profile.ts`. Поле `displayName` обязательно: отсутствующее поле — ошибка, а пустая строка после `trim()` — допустимое и осознанно сохранённое значение. `age` может отсутствовать, но переданный возраст должен быть целым неотрицательным числом. Теги нужно очистить от пробелов, сохранив их порядок и повторы.

## Ограничения

- Не используйте `JSON.stringify`/`JSON.parse` для копирования.
- Не мутируйте входной объект и массив `tags`.
- Не используйте `any` и не заменяйте runtime-проверки assertion-ами.
- Явно различайте отсутствующее поле, пустую строку и число `0`.
- Для ошибки возвращайте все найденные проблемы в стабильном порядке полей: `id`, `displayName`, `age`, `tags`.

## Проверка
