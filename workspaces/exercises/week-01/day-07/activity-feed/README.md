# Typed activity feed

## Задача

Реализуйте вертикальный срез: провалидируйте массив `unknown`-событий, стабильно сгруппируйте доменные activities по UTC-дате и отобразите группы React-компонентом. Parsing, transformation и presentation должны оставаться отдельными слоями.

## Ограничения

- Не используйте `any` и не доверяйте generic у `fetch`/`JSON.parse`.
- Не смешивайте runtime parsing с React-компонентом.
- Не мутируйте события и не сортируйте входной массив на месте.
- Не храните сгруппированный результат как derived state.
- Используйте стабильные `id`, а не индексы, в качестве React key.
- Добавьте минимум пять собственных тестов сверх контрактных примеров.

## Работа

Контракты находятся в `src/activity.ts`, группировка — в `src/group-activities.ts`, presentation — в `src/activity-feed.tsx`. Заготовки типизированы, но намеренно не содержат решения.

Из каталога упражнения:

```text
npm install
npm run typecheck
npm test
```

При запуске через корневой harness зависимости уже доступны после корневого `npm install`.
