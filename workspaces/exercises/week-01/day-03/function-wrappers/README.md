# Обёртки функций: `once` и `memoizeOne`

## Задача

Реализуйте две типобезопасные функции высшего порядка. `once` вызывает исходную функцию только при первом обращении и затем возвращает тот же результат. `memoizeOne` хранит результат последнего вызова и повторно использует его, только когда совпали receiver, число аргументов и каждый аргумент по `Object.is`.

Обе обёртки должны сохранить tuple аргументов, результат и тип `this` исходной функции.

## Ограничения

- Не используйте `any`.
- Не вызывайте исходную функцию лишний раз.
- Считайте `undefined` полноценным закешированным результатом.
- Передавайте текущий receiver исходной функции.
- Для `memoizeOne` не делайте глубокое сравнение и не сериализуйте аргументы.
- Если исходная функция бросила ошибку, не кешируйте этот вызов.
